# SentiArab-LEV

Sentiment Analysis for Levantine Arabic

## Project Overview

This project focuses on sentiment analysis for Levantine Arabic text.

## Structure

- **notebooks/**: Jupyter notebooks for exploration and analysis
- **dataset/**: Data files used in the project
- **figures/**: Generated visualizations and plots
- **report/**: Analysis reports and documentation
- **presentation/**: Presentation slides and materials
